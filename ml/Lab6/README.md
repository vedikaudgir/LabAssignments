# Lab 6 — Clustering

Implements K-Means, agglomerative clustering (single/complete/average linkage), divisive clustering, and dendrogram visualization. K-Means and hierarchical assignments are written from scratch; sklearn/scipy are used only for reference plotting/data support. Run `python src/main.py`.

Data: reproducible synthetic blobs and the existing local Iris CSV using petal length/width. Outputs are saved in `outputs/`. Outliers are explicitly included in a separate K-Means experiment.
